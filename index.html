《雨夜守护小屋》隐私政策

更新日期：2026-08-23 ｜ 生效日期：2026-08-22

欢迎使用《雨夜守护小屋》微信小游戏（以下简称"本游戏"）。我们高度重视您的个人信息和隐私保护。本政策向您说明我们如何收集、使用、存储和保护您的信息，以及您所享有的权利。请您在使用本游戏前仔细阅读并理解本政策。

一、我们收集的信息

在您使用本游戏的过程中，我们可能收集以下信息：

  • 微信账号基础标识：通过微信登录能力获取您的微信 OpenID 等基础标识信息，用于游戏账号识别、进度关联与广告效果统计。
  • 设备信息：包括设备型号、操作系统版本、屏幕参数、网络状态等，用于显示适配、运行优化与崩溃排查。
  • 游戏存档数据：包括守夜进度、章节解锁状态、暖光 / 印章 / 回忆碎片等虚拟物品、家具 / 主题 / 宠物解锁记录、游戏设置等。上述数据默认保存在您的设备本地（通过微信本地存储能力），不会上传至开发者自有服务器。
  • 您主动输入的文本：如您自定义的小屋名称、宠物昵称等文字内容，仅保存在设备本地，不上传开发者服务器。
  • 广告相关标识符：由微信广告 SDK（优量汇）生成，用于向您展示激励视频等广告及广告效果统计。
  • 实名与防沉迷信息：根据相关法律法规，本游戏接入微信实名认证与未成年人防沉迷系统，相关实名信息由微信 / 腾讯按法律法规要求处理，开发者不额外收集、不存储该类信息。
我们不收集与游戏功能无关的个人信息，不强制索取任何非必要权限；相册、相机、麦克风、位置等敏感权限本游戏均不使用。

二、我们如何使用信息

我们收集的信息仅用于以下目的：

  • 提供、维护并优化本游戏服务；
  • 适配不同设备显示、保障运行稳定与安全；
  • 保存并恢复您的游戏进度；
  • 展示激励视频广告（广告收益用于维持游戏运营）；
  • 履行法律法规要求的实名认证与未成年人保护义务。

三、第三方 SDK / 服务

  • 微信广告 SDK（腾讯优量汇）：用于展示激励视频广告，其数据处理遵循《微信隐私保护指引》。
  • 微信基础能力 SDK（腾讯）：用于微信登录、游戏分享等能力，由微信按《微信隐私保护指引》处理。
  • 微信实名认证与防沉迷系统（腾讯）：用于落实未成年人保护合规要求。

四、信息的存储与保护

  • 我们仅在为实现本政策所述目的所必需的最短期限内保存您的信息。
  • 您的游戏存档与自定义文本保存在设备本地；我们采用通行的安全技术措施保护信息安全，防止信息泄露、篡改或丢失。
  • 我们不会向第三方出售您的个人信息。除法律法规要求或为提供本游戏必要能力（如上述第三方 SDK）外，我们不会向第三方提供您的个人信息。

五、您的权利

您对自己的个人信息享有以下权利：

  • 查询、复制、更正您的个人信息；
  • 删除您的个人信息；
  • 撤回您已作出的授权同意（撤回不影响撤回前基于同意已进行的信息处理）；
  • 如您希望行使上述权利，可通过本政策第七条的联系方式与我们联系。

六、未成年人保护

  • 我们高度重视未成年人保护。若您未满 18 周岁，请在监护人陪同下使用本游戏。
  • 本游戏已接入微信实名认证与未成年人防沉迷系统，对未成年人游戏时长与消费进行限制。
  • 我们不会主动收集未成年人的敏感个人信息；监护人可代未成年人行使本政策所述各项权利。

我们可能适时更新本政策。当政策发生重大变更时，我们会在本游戏内或以其他适当方式提示您，并更新本政策右上角的"更新日期"。您在更新后继续使用本游戏，即视为您已阅读并同意更新后的政策。
